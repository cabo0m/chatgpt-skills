# ChatGPT Skills

Publiczna kolekcja praktycznych skilli do ChatGPT tworzonych przez MorenaTech.

## Struktura

Każdy skill ma własny katalog w `skills/`.

```text
skills/
  nazwa-skilla/
    SKILL.md
    README.md        # opcjonalnie
    examples/        # opcjonalnie
    assets/          # opcjonalnie
```

## Założenia

- jeden katalog = jeden niezależny skill,
- główna instrukcja skilla trafia do `SKILL.md`,
- przykłady i materiały pomocnicze trzymamy obok skilla,
- skill powinien być możliwie konkretny, testowalny i łatwy do skopiowania.

Pierwszy planowany skill: obróbka zdjęć produktowych do sklepu internetowego.
