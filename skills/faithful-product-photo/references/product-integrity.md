# Product Integrity Contract

A faithful edit is judged by factual product continuity, not by polish.

## Instance-level review

Review every repeated object separately. For each instance record:

- color
- visible parts
- connector / cap / handle / lid type
- ownership of those parts
- distinctive bends, folds, labels, defects, and asymmetry

A multi-pack must not be validated by checking only the total number of plugs or objects.

## Topology matters

For cables and similar products, topology means the visible relationship between:

- cable body
- branch
- connector
- tie
- neighboring cable

A connector that exists in both source and output can still be wrong if it moved from one cable to another.

## Preserve imperfection

Do not normalize:

- dents
- slightly uneven packaging
- asymmetrical cable coils
- manufacturing marks
- scuffs
- minor deformation

unless the user explicitly asks for retouching and the change does not alter what the buyer receives.

## High-risk repeated products

Use extra care for:

- cable packs
- earbuds
- adapters
- batteries
- cutlery sets
- cosmetics multipacks
- hardware kits
- tool sets
- jewelry pairs
- shoe pairs
- multi-color variants
