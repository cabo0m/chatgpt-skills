# Starter prompts

- Usuń tło i zostaw obiekt na prawdziwej przezroczystości. Strict binary: tło alpha 0, obiekt alpha 255, bez wartości pośrednich.
- Remove the background only. Preserve the subject exactly and return a real transparent PNG with binary alpha.
- Usuń tło, ale użyj natural-edge dla włosów. Nie zmieniaj osoby ani niczego nie dodawaj.
