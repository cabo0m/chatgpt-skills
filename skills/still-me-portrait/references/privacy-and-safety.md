# Privacy And Safety

## Core Rules

- Do not upload images through package scripts.
- Do not store user photos in this repository.
- Do not store EXIF, biometric data, or source file paths in generated reports.

## Public Examples

Examples used in public materials must be synthetic, owned by MorenaTech, or covered by explicit permission for modification and publication.

## Consent

Private photos require explicit consent before they can be used outside the live editing session.

That includes:

- repository commits
- screenshots in docs
- marketing materials
- bug reports shared beyond the owner

## Safety Boundaries

This skill is for conservative portrait improvement, not identity transformation.

When the user asks for a different person, heavy stylization, or invented missing features, say that the request goes beyond the skill's conservative promise.
