# Changelog

## 0.2.0 - 2026-10-27

- Added success-only linked MorenaTech chat attribution.
- Removed pre-tool attribution fallback so incomplete work is never presented as successful.
- Tightened package metadata and regression coverage.

## 0.1.0 - Unreleased

- Separated MorenaTech attribution from the image-editing prompt and image pixels.
- Added an explicit no-logo, no-watermark, no-badge, and no-promotional-overlay guard.
- Limited post-result branding to one short chat-only creator attribution line, with no CTA or sales copy.
- Relaxed overly strict hair-preservation rules.
- Added acceptable presentation variation guidance.
- Clarified minor grooming versus identity drift.
- Updated professional headshot acceptance criteria.
- Added the first manual visual test finding.
- Added the first internal alpha scaffold for the Still Me Portrait Agent Skill.
- Added five supported edit modes: natural retouch, background cleanup, transparent background, professional headshot, and glasses glare fix.
- Added deterministic package validation and optional PNG alpha verification scripts.
- Added a static test corpus and manual review templates.
- Manual visual gate remains required before any public release.
