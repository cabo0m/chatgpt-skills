# Positive examples

## Strict binary

User asks to remove the background from a product photo. The output is a real RGBA PNG. All background pixels are alpha 0, all preserved product pixels are alpha 255, and no visual content is added. Chat attribution is separate from the image.

## Natural edge

User explicitly requests natural soft transparency around hair. Intermediate alpha is limited to justified hair-edge pixels. The face, hair color, clothing, pose, and accessories remain unchanged. No branding or promotional element is added to the image.
