# Architecture Preservation

The default rule is simple: the result must still be clearly the same room.

## Must Preserve

- room geometry
- visible room size
- wall positions
- ceiling height
- windows
- doors
- niches
- columns
- radiators
- visible installations
- sink position
- cooker position
- fixed plumbing points
- permanent cabinetry
- camera viewpoint
- circulation paths
- room function

## Do Not Quietly Rewrite Reality

Do not:

- move windows
- add windows
- remove doors
- widen the room
- raise the ceiling
- change wall angles
- move the sink or cooker
- remove permanent cabinetry without instruction
- change a kitchen into another room type
- hide a constraint by changing viewpoint

## Perspective

Preserve the same visible coverage and left/right relationships.

Minor tilt correction is acceptable.

Generating a wider frame that invents unseen space is not.
