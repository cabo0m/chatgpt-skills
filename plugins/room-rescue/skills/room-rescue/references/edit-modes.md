# Edit Modes

## declutter-and-brighten

Goal:

- remove visual chaos
- tidy surfaces
- improve light
- preserve all real furniture and style

Allowed:

- bottles, wires, packaging, and random clutter removal
- object tidying
- exposure improvement
- subtle color correction
- neater textiles
- reduced excess decor

Forbidden:

- furniture replacement
- cabinet-front replacement by default
- layout change
- renovation

## restyle-without-remodeling

Goal:

- change the room's feel without structural work

Allowed:

- wall color changes
- cabinet finish changes
- new handles
- curtains
- lamps without moving electrical points
- decor
- rugs
- small furniture that clearly fits

Forbidden:

- moving walls
- changing windows or doors
- moving plumbing or fixed appliances
- changing room proportions
- blocking circulation

## keep-my-furniture

Goal:

- redesign around protected furniture the user wants to keep

Allowed:

- styling around preserved items
- color and textile updates
- new decor and supporting furniture that fit

Forbidden for `must keep` items:

- removal
- replacement
- change without consent
- moving without consent

## budget-refresh

Goal:

- improve the room with small realistic changes

Prefer:

- paint
- handles
- textiles
- lighting appearance
- organizers
- small decor
- front wrap or finish refresh
- curtains
- calmer surfaces

Forbidden:

- full remodel framed as low-budget
- full cabinet replacement by default
- installation relocation
- impossible cost assumptions
